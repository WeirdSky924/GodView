# 角色立场约束规范

## 核心原则

每个角色都有明确的立场定位，所有行为必须符合该定位。**反派的任何行为不能以"帮助主角实现其核心目标"为出发点。**

## 一、角色立场分类

### 1. 主角阵营

| 立场类型 | 角色类型 | 行为特征 |
|----------|----------|----------|
| 主角 | protagonist, co_protagonist | 追求自身目标，可能接受他人帮助 |
| 盟友 | deuteragonist, mentor, best_friend, major_ally | 主动帮助主角，与主角目标一致或相关 |
| 家人 | family_member, guardian | 关心主角，但可能有自己的考虑 |
| 中立友好 | recurring, informant | 不主动对抗主角，可能提供有限帮助 |

### 2. 反派阵营

| 立场类型 | 角色类型 | 行为特征 |
|----------|----------|----------|
| 宿敌 | archenemy | 与主角核心目标直接对立 |
| 主要反派 | major_antagonist | 阶段性对抗，目的明确 |
| 篇章反派 | arc_antagonist | 特定篇章的敌人 |
| 爪牙 | minion | 执行反派命令，没有独立目标 |

### 3. 中立/变数

| 立场类型 | 角色类型 | 行为特征 |
|----------|----------|----------|
| 竞争对手 | rival | 与主角竞争，但非敌人 |
| 变数 | wild_card, mystery_figure | 立场不明，可能随时变化 |
| 双面间谍 | double_agent | 表面帮助，实际另有目的 |

## 二、反派行为禁区

### 绝对禁止的行为

反派**不能**做以下事情（除非有合理动机解释）：

1. **主动帮助主角实现核心目标**
   - ❌ 告诉主角关键情报
   - ❌ 给主角关键道具
   - ❌ 教主角关键技能
   - ❌ 解救主角于危难

2. **无代价的善意行为**
   - ❌ 无理由放过主角
   - ❌ 无条件的合作
   - ❌ 牺牲自己帮助主角

### 允许的行为（需合理动机）

反派可以做出看似帮助主角的行为，但必须有**自私动机**：

| 行为 | 合理动机 | 实际目的 |
|------|----------|----------|
| 告诉情报 | 情报有假/有陷阱 | 误导主角 |
| 给道具 | 道具有追踪/诅咒 | 控制或监视主角 |
| 合作 | 有共同敌人 | 利用后消灭主角 |
| 放过 | 有更大阴谋 | 让主角做更多事再杀 |

### 反派行为的合理模式

```
反派行为 = 自身利益 → 行为执行 → 意外影响（可能有利于主角）
                                        ↓
                                   但这是副作用，非目的
```

## 三、角色行为自检规则

### 每个涉及角色的决策必须检查：

```
1. 角色立场是什么？(protagonist/antagonist/neutral)
2. 这个行为是否符合其立场？
3. 如果是反派做出有利主角的事：
   - 有没有自私动机？
   - 是否有隐藏陷阱？
   - 是否在利用主角？
   - 主角是否知道真实目的？
```

### 反派行为三问

在编写反派任何行为前，必须回答：

1. **这个行为服务于反派的什么目标？**
2. **这个行为如何损害或阻碍主角？**
3. **如果看起来在帮助主角，真正的目的是什么？**

## 四、常见错误案例

### 错误案例 1：反派无理由放水

```
❌ 错误：反派本可以杀死主角，但"觉得有意思"就放过了。

✅ 正确：反派放过主角是因为：
   - 主角体内有反派的追踪印记
   - 反派想让主角带领自己找到更大的目标
   - 反派在主角身上种下了诅咒，放长线钓大鱼
```

### 错误案例 2：反派主动提供情报

```
❌ 错误：反派主动告诉主角宝藏的位置。

✅ 正确：反派告诉主角位置是因为：
   - 那里有反派布置的陷阱
   - 反派想借主角的手打开封印
   - 那是假情报，误导主角
```

### 错误案例 3：反派对主角产生好感

```
❌ 错误：反派因为主角的"真诚"决定帮助主角。

✅ 正确：反派表面帮助是因为：
   - 想从主角身上获取某些信息
   - 在利用主角对抗另一个敌人
   - 准备在关键时刻背叛
```

## 六、特殊场景处理

### 场景 1：反派与主角暂时合作

**条件**：
- 存在共同敌人或共同利益
- 双方都知道这是临时的
- 各自保留算计

**处理方式**：
- 明确合作的期限和条件
- 描写双方的戒心
- 为后续背叛或冲突埋下伏笔

### 场景 2：反派转变为盟友

**条件**：
- 必须有充分的转变理由
- 转变过程需要篇幅描写
- 转变后仍需付出代价

**处理方式**：
- 先明确转变触发事件
- 描写内心挣扎和抉择
- 原来的反派属性转变为新的角色定位

### 场景 3：误解型反派

**条件**：
- 角色看起来像反派但实际不是
- 需要前期的错误信息铺垫
- 揭示真相时要有合理性

**处理方式**：
- 确认角色实际立场（不是真反派）
- 揭示真相前的行为要有合理性暗示
- 真相揭示后要重新定义角色

## 七、Agent 专项约束

### 对于 Plot Outline Agent

生成大纲时：
- 明确标注每个出场角色的 role_type
- 检查反派行为是否符合立场
- 如有反派出场，说明其行为动机

### 对于 Writer Agent

写作时：
- 在开头明确角色立场信息
- 反派对话和行为要符合立场
- 任何看似善意的反派行为必须有隐藏目的

### 对于 Character Agent

角色扮演时：
- 严格遵守角色的立场定位
- 反派角色不能无理由帮助主角
- 如有合作，保持戒心和算计
