# 章节钩子设计技能

## 核心理念

网文的钩子设计决定了读者的追读率。好的钩子让读者欲罢不能，差的钩子让读者弃书。

## 一、开篇钩子类型

### 1. 冲突开篇

直接进入冲突场景，制造紧张感。

```
示例：剑尖距离咽喉只有三寸。
```

**适用场景**：
- 战斗章节
- 危机时刻
- 高潮前后

### 2. 悬念开篇

抛出悬念，引发读者好奇。

```
示例：三天后，整个宗门都将为这个决定而战栗。
```

**适用场景**：
- 重要事件前
- 转折章节
- 新卷开头

### 3. 反差开篇

与上一章结尾形成反差，制造期待。

```
示例：上一章结尾：他信心满满地推开门。
     本章开头：门内，是一片死寂。
```

**适用场景**：
- 连续章节
- 剧情转折
- 意外发展

### 4. 时间跳跃开篇

跳过无聊的过渡，直接进入关键时间点。

```
示例：三日后，宗门大比。
```

**适用场景**：
- 时间跨度
- 事件预告
- 快速推进

### 5. 视角切换开篇

从其他视角切入，提供新信息。

```
示例：与此同时，千里之外的洞府中...
```

**适用场景**：
- 多线叙事
- 反派视角
- 伏笔暗示

## 二、结尾钩子类型

### 1. 悬念式结尾

抛出问题，让读者想知道答案。

```
示例：就在这时，天空裂开了一道缝隙。
```

**强度**：⭐⭐⭐⭐⭐
**适用**：所有章节，尤其是过渡章节

### 2. 危机式结尾

在关键时刻戛然而止。

```
示例：他还没来得及反应，黑暗已经将他吞没。
```

**强度**：⭐⭐⭐⭐⭐
**适用**：高潮前章节

### 3. 转折式结尾

揭示意料之外的信息。

```
示例："你猜对了，"那人缓缓摘下面具，"我就是他。"
```

**强度**：⭐⭐⭐⭐
**适用**：剧情转折章节

### 4. 期待式结尾

预告接下来的精彩内容。

```
示例：明天的拍卖会，必将惊天动地。
```

**强度**：⭐⭐⭐
**适用**：日常章节、过渡章节

### 5. 承诺式结尾

明确主角接下来的目标。

```
示例："三天后，我会亲自去取他的项上人头。"
```

**强度**：⭐⭐⭐⭐
**适用**：复仇章节、目标确立章节

### 6. 反转式结尾

推翻读者预期，制造震撼。

```
示例：他终于明白，原来一切从一开始就是个局。
```

**强度**：⭐⭐⭐⭐⭐
**适用**：关键转折章节

## 三、钩子设计原则

### 1. 强度匹配原则

| 章节类型 | 开篇钩子 | 结尾钩子 |
|----------|----------|----------|
| 开篇章节 | 强（吸引新读者，但优先来自近场压力/异常/规则冲突） | 强（留住读者） |
| 过渡章节 | 中（维持兴趣） | 强（推动追读） |
| 高潮章节 | 强（制造紧张） | 中（给读者喘息） |
| 结尾章节 | 中（承接上文） | 弱/强（视情况） |

### 2. 因果可追溯原则

钩子可以神秘，但不能无因。设计开篇或结尾钩子时，必须至少在大纲层面知道：

```text
钩子的真实来源 → 为什么此刻出现 → 为什么影响主角/当前场景 → 主角能感知到什么 → 暂时隐藏什么 → 后续如何兑现
```

不要为了强钩子随机投放灾难、国家机密、高阶人物、神器、追杀或终局真相。如果主角暂时不知道原因，必须把原因放在大纲备注/writing_hints 中，而不是让事件没有缘由。

黄金三章的强钩子必须同时承担读者信息赋予：让读者通过资源分配、身份限制、局部封锁、异常物件、代理人追索、规则惩罚等近场张力理解世界，而不是直接跳到最高级冲突。钩子强度来自“问题贴近主角且后果明确”，不来自无因抬高威胁等级。

**示例**：
- 不合适：`主角刚出门，天空突然掉下一份国家机密。`
- 合适：`档案馆被人纵火后，一页被烧毁的名单被风卷进贫民区水渠；主角只看到自己的住址被圈出，不知道名单真实等级。`
- 不合适：`结尾突然出现最终反派的真实身份。`
- 合适：`结尾出现一个反复出现的残缺符号；读者知道它重要，但主角只把它当成追踪标记。`

### 3. 角色知识边界原则

钩子制造的信息差必须区分读者与角色：

- 读者可以获得比主角更多的紧张感，但主角不能据此行动。
- 主角只能根据亲眼所见、传闻、残缺线索、职业经验、能力感知或他人告知做判断。
- 宪法级设定、国家级机密、隐藏计划可以成为钩子的真实来源，但不能无来源地进入主角认知。

### 4. 节奏控制原则

不要每章都用最强钩子，会形成疲劳：

```
强钩子 → 中钩子 → 强钩子 → 弱钩子 → 强钩子
```

### 5. 期待管理原则

钩子制造的期待必须在后续章节兑现：

- 小悬念：1-2章内解决
- 中悬念：3-5章内解决
- 大悬念：跨卷解决

### 6. 追读优化原则

网文黄金三章法则：

- 第一章结尾：必须有强钩子，但优先来自 life_pressure / rule_pressure / local_anomaly / proxy_conflict，不默认使用 core_threat
- 第二章结尾：必须有强钩子，最好展示第一章异常的后果，让冲突与主角产生更强关联
- 第三章结尾：让读者确信值得追，形成阶段目标或选择代价，可以露出 mainline_edge，但不得无因揭开完整终局真相

开篇钩子的目标是“信息通过冲突赋予”：读者既要看懂主角和世界入口，也要感到问题正在逼近。

## 四、钩子禁区

### 不要做的事

1. **钩子太多太密** - 悬念堆积，读者麻木
2. **钩子不兑现** - 悬念烂尾，失去信任
3. **钩子太弱** - 读者无感，直接划走
4. **钩子与内容不符** - 标题党，引起反感
5. **同一类型钩子重复** - 审美疲劳

## 五、章节钩子检测清单

生成大纲时，检查以下要素：

```
[ ] 开篇是否有钩子？
[ ] 结尾是否有钩子？
[ ] 钩子强度是否匹配章节位置？
[ ] 钩子制造的期待是否会在后续兑现？
[ ] 钩子的真实来源、出现时机和影响对象是否有因果依据？
[ ] 主角是否只基于可知线索做判断，而没有直接知道隐藏真相/国家机密？
[ ] 是否与最近的钩子类型重复？
```
